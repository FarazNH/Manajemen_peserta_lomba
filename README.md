
# 🏆 Sistem Manajemen Data Peserta Lomba

Program sederhana berbasis bahasa C yang dibuat sebagai Tugas Besar mata kuliah Algoritma dan Pemrograman.

## 📌 Deskripsi
Program ini digunakan untuk mengelola data peserta lomba, melakukan perhitungan nilai akhir berdasarkan bobot penilaian, serta menentukan peringkat juara secara otomatis.

## ✨ Fitur Program
- Menambahkan dan menampilkan data peserta
- Mengubah dan menghapus data peserta
- Mencari peserta berdasarkan ID
- Mengatur bobot penilaian
- Menghitung nilai akhir peserta
- Mengurutkan peserta berdasarkan nilai
- Menampilkan juara 1, 2, dan 3
- Menampilkan statistik nilai peserta

## 💻 Teknologi
- Bahasa Pemrograman C
- Program berbasis terminal/console

## 🚀 Cara Menjalankan
1. Unduh file `Manajemen_peserta_lomba.c`.
2. Buka file menggunakan VS Code atau IDE yang mendukung bahasa C.
3. Compile program menggunakan GCC:

   ```bash
   gcc Manajemen_peserta_lomba.c -o lomba
   ```
   
4. Jalankan program:
   - Windows: `.\lomba.exe`
   - Linux/macOS: `./lomba`

5. Pilih menu sesuai kebutuhan.
